# Validator rules: tool sources and provided tools

Decisions [0008](../../decisions/0008-tool-sources.md),
[0011](../../decisions/0011-control-layer-provided-tools.md) and
[0048](../../decisions/0048-a-provided-tool-names-a-source-when-tools-are-listed.md).
Each row is one diagnostic site. The Go, Zig and Rust columns name the function
that emits it, `—` where that tree has none. Rows whose expectation is settled
later (an admission, a refusal) name the function that sets the expectation.
Fixtures are manifest ids.

Rust (`oap-validation`) ports none of these units yet. Its only rows here are
the generic tool lifecycle checks in `state/interactions.rs`.

## Divergences

- [OPEN-0008-1](../../research/validator-divergences.md#open-0008-1): Zig judges
  a reported source's description only for attached sources; Go also judges
  declared ones.
- [OPEN-0008-2](../../research/validator-divergences.md#open-0008-2): only Go
  requires a session-scoped catalog to name its session on the envelope, and
  only Go checks `tool_call_id` on the resolve pair.
- [OPEN-0011-1](../../research/validator-divergences.md#open-0011-1): Zig does
  not read a disclosed `name_pattern`.
