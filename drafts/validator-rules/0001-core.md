(`drafts/agent-control-core.md`, `drafts/conformance.md`): the rows behind the
core envelope, request/response, run lifecycle, interaction and capability
diagnostics. Run controls, tools, steer, content completion and pending-at-
terminal rules sit in their own groups' files. Format: [README](README.md).
