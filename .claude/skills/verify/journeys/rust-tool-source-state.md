# Rust tool-source calls and snapshots

Run `cargo test --manifest-path rust/Cargo.toml -p oxap-validation --test tool_source_state`
and the shared `rust-go-parity.py` journey from the repository root.
Calls must match the current session catalog or descriptor attribution. An
advertised, published attribution makes an omitted source `unattributed_call`.
Unknown or conflicting sources draw `unmatched_tool_source` at `/payload/source`.
Open responses may fill compatible unstated attachment members. Later snapshots
must preserve the exact attached/declared source union, with one descriptor per id.
Invalid snapshots draw `session_state_mismatch` or `duplicate_tool_source` at
`/payload/sources`; repairs and the shared positive traces must pass.
The baseline in SKILL.md runs the shared replay and isolated PTY proof too.
